# game-worldbuilder

A "god game" in the spirit of *Populous* (1989): you shape the land, your
followers settle it, and their worship powers your miracles against
a rival deity.

Status: **planning**. Built with Godot 4, aiming for a gorgeous stylised "living miniature world" look. See [`docs/GAME_PLAN.md`](docs/GAME_PLAN.md) for the
design, technical approach, and milestone roadmap.
